## Why I vibe code:

  Ever since I started using OpenAI's chatgpt since 2023, I've only used the main chatbot feature. I first started using it as a supplement to my googling about programming. I slowly noticed myself drifiting away from StackOverflow and strickly asking coding questions to GPT. 
Up to this point I have never being someone that coded for a living (and I am still not - some please hire me). So I have been hesitant to just tell the LLM to give me the code to solve my problems. With this hesitation stuck in my mind, I would mainly ask the GPT to explain to me pices of code that made no sense to me, to review my code and to suggest any improvements. 
As a noob, I think the explainations were pretty good.

For context, I was not a complete noob. By this point in my life I had already taken a couple couses in programming at school. I had even done some low level programming to program a micro controller to create a miniture traffic light. I had made some automation scripts in python. And programmed PLCs to move industrial machinary. So I've always done programming but not in the Syllicon valley sense. That's why I can confidently say GPT was teaching me something valuable.

 I was able to understand the logic behind someone elses code, get out of issues with my own code quicker. But yeah, I never fully just code built entirely by LLMs. 

Jump to now, 2025. LLMs are no longer just useful chatbots. They have been integrated into your favorite dev enviroment all thanks to agents.



This website is my was mostly built through the art of vibe coding.
