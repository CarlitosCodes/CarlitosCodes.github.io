## Why I vibe code:

Ever since I started using OpenAI's ChatGPT in 2023, I've primarily used the main chatbot feature. I initially used it as a supplement to my Google searches about programming. Gradually, I noticed myself drifting away from Stack Overflow and asking coding questions exclusively to GPT.

Up to this point, I have never been someone who codes for a living (and I still am not—someone please hire me). Because of this, I have been hesitant to simply ask the LLM to generate code to solve my problems. With this hesitation in mind, I primarily asked GPT to explain pieces of code that didn’t make sense to me, to review my code, and to suggest improvements.

As a beginner, I think the explanations were quite good.

For context, I was not a complete novice. By that point in my life, I had already taken a few programming courses in school. I had even done some low-level programming to program a microcontroller and create a miniature traffic light. I had written some automation scripts in Python and programmed PLCs to operate industrial machinery. So, while I have always engaged in programming, it was not in the traditional Silicon Valley sense. That’s why I can confidently say GPT was teaching me something valuable.

I was able to understand the logic behind someone else’s code and resolve issues in my own code more quickly. However, I never fully relied on code built entirely by LLMs.

Fast forward to 2025: LLMs are no longer just useful chatbots. They have now been integrated into developers’ favorite environments—all thanks to agents.

This website was mostly built through the art of “vibe coding.”
