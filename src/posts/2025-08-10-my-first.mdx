## Why I vibe code:

  Ever since OpenAI released GPT 3.0, I only used the main chatbot feature. I first started using it as a supplement to my google regarding programming. I slowly started drifiting away from StackOverflow and strickly asked coding questions to Gpt. 
Up to this point I have never being someone that code for a living (and still not - some please hire me). So I have been hesitant to just tell the LLM to give me code to solve my problems. With this hesitation stuck in my mind, I would mainly ask the GPT to explain to me pices of code, to review my code and to suggest any improvements. 
I think the explainations were good. I was able to understand the logic behind someone elses code, get out of issues with my own code quicker. But yeah, I never fully just code built entirely by LLMs. 

Jump to now, 2025. LLMs are no longer just useful chatbots. They have been integrated into your favorite dev enviroment all thanks to agents.



This website is my was mostly built through the art of vibe coding.
